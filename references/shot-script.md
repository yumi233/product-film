# 视频脚本与分镜

用户审的是**画面和节奏**，所以正文用中文写清楚画面；英文提示词放在任务 JSON 里，不放进给用户看的文档。

## 文档结构
1. 一句话：这部片子讲什么。
2. 全片结构表：每部分的时间、讲什么、看到什么。**单件和整体都要有**。
3. 剪辑规则（下面那一节，抄进去）。
4. 每部分一张镜头表（不能写「同上」「每段同理」）。
5. 声音：旁白（每句的位置）、字幕、配乐节奏、环境声。
6. 关键帧清单：已有 / 还要做。
7. 预算：条数、秒数、币数、余额、重抽余量。
8. 请用户确认的 2–4 个问题。

## 镜头表的列
| 镜 | 生成 | 起始关键帧 | 画面 | 剪辑后 | 切到下一镜 | 旁白 / 字幕 |
|---|---|---|---|---|---|---|

- **生成**：送去 H3 的秒数，10 或 15。**剪辑后**：保留几秒；一条长镜可以写「远景 4s + 特写 4s」，表示拆成两个镜头用。
- **起始关键帧**：编号 + 一句话 + 状态（已做 / 待做 / 待修）。
- **切到下一镜**：写具体剪法，见下。

## 图文分镜审核交付
脚本文档与分镜图要一起出现，推荐使用本地HTML画廊或其他能直接显示图文的单一审核文件。每个镜号一张卡片，依次显示：

1. 镜号、同一版脚本的成片时间、保留时长。
2. 对应图片，说明它是起始帧、中段、爆炸展开态或合拢态。
3. 画面、人物动作、运镜、接下一镜的具体剪法。
4. 视频模型需要的环境音效，以及另轨后期加入的旁白与字幕。
5. 素材来源状态：新生成、沿用候选或待修。另附按镜号顺序的整幕总览图。

用户要看新的分镜图时，实际生成并对照参考图核查，不能仅重排旧候选图冒充新图。缺图时明确标记部分预览；完整图文审核稿必须所有镜号都有对应画面。同一条生成素材拆作多个剪辑镜头时，可共用起始图，但须说明哪些机位或动作还需中段示意，不把同图当成不同机位已经制作完成。

交付前核对时间轴无间隙或重叠、章节时长与总长相等、镜号不重复、每镜图片可打开，并连续查看整组结构、光线、位置与动作。审核的是这一版图文分镜，不能把“继续整理”“先看看”解释为已批准新视频生成。先修改现有视频时只重剪已有素材，标记修改范围并保留旧版本；后续新增镜头仍等图文分镜审核。

## 剪辑规则：不接首尾，靠剪法保证流畅
首尾帧接续（上一条的尾帧 = 下一条的首帧）试过，效果不好：H3 不一定从首帧开始、也不一定停在尾帧；相邻两条构图几乎一样，剪在一起像跳切；镜头被锁死在两张图之间，动感不足。改用：

1. **每条只给一张起始关键帧**（产品不清楚时再加最多 4 张渲染图），H3 默认生成 6 秒，剪辑只用最稳的 3–5 秒（`stable_window.py` 自动挑）。**不加速**：1.3–2 倍速会在 24 帧下不均匀丢帧，画面一顿一顿。
2. **相邻镜头必换景别**：远 → 近、全 → 特写，差得够大，切过去就自然。
3. **在动作中切**：推近中、零件合拢落定那一下、手伸出去那一瞬间。
4. **方向一致**：一段里镜头和画面运动朝同一个方向。
5. **形状 / 位置呼应**：真实的湖 → 画中的湖；台面在画面中间 → 下一镜台面也在中间。
6. **声音先行**：下一场景的环境声提前约 0.5 秒进来。
7. **先定配乐再剪**：用 `music_phrases.py` 找乐句起点，每章第一个镜头落在乐句起点上；只伸缩上一章末尾的空镜（2.5–5 秒）来对齐。
8. **一条长镜拆两次用**：15 秒里先远后近，剪成两个镜头，中间插别的。
9. **转场时长**：章节之间叠化约 0.9 秒，画卷↔实物约 0.6 秒，其余 0.3 秒软切。0.15 秒的近似硬切在不同空间之间（画卷→白棚→实景→空镜）看起来像跳切。
10. **镜头最短 3 秒**，特写 3–3.5 秒；同一件产品连着的镜头景别必须拉开（远/近/特写交替），同景别连切像跳帧。
11. **章节之间插 2–3 秒空镜**（水面、竹影、檐滴、雨），给观众喘气，也给配乐换句。

## 声音分工
- 视频提示词里仍写环境音效、禁止人声（防止模型说话），但**成片默认不用模型原声**：实测是低频轰鸣加嘶声。环境声用真实录音按场景铺（见 audio.md）。旁白列仅供后期录音与剪辑，不进入视频提示词。
- 没有本机Qwen3时，先向用户索要最终旁白音频及对应文稿。不要因为缺模型就跳过询问，也不把短音色样本当作最终录音。
- 独立旁白按实测长度安放，两句之间不重叠（cut.py 打印的 vo 区间逐条查）。

## 产品镜头规则
- **每件产品一站（用户认可的结构）**：画中出处 → 出画 → 白底整件（加名称卡）→ 一个新视角（俯拍 / 贴地仰拍 / 光影透过结构投在地上 / 主题元素的影子落在产品上）→ 2–3 个节点或材质特写（产品方渲染图做亚像素慢推，`still_push.py`）→ 线描人在用（白棚）→ 真人实景 → 2 秒空镜。最后：全家福 → 组合 → 实景 2–3 场 → 收尾画面 → 片名卡。
- **用户可能不要的**：爆炸图、三视图和带尺寸的线稿（本项目用户说「没帮助」「这种都不要」）。先问，不默认放。
- **爆炸图**（用户要时）：先完整展示爆炸状态，停 1–2 秒，再合拢，最后推近细节。合拢段 4–8 秒，越长越容易变形。
- **造型以渲染图为准**：每个产品镜头的参考图里都要有该产品的渲染图；有人的镜头里，椅子、桌子也要带渲染图。
- **器物配套**：茶具、灯具用产品自带或配套的（不锈钢电水壶、白瓷），不出现紫砂、铁壶、藤编。
- **单件 + 整体**：每件产品有自己的段落（画中 → 出画 → 爆炸 → 真实空间），最后一段所有产品同在一个空间、有人在用。

## 节奏
- 全片 3–4.5 分钟：开场 30–50 秒，每件产品一站约 25–30 秒，整体 30–40 秒，收尾 15 秒。要拉长就加内容（新视角、在用、空镜），不靠放慢或拉长镜头。
- 旁白 10–14 句、总长约 50 秒，其余留给画面和音乐。
- 每部分结尾留一下（空镜、杯子放下、全景），给下一部分一个入口。

## 预算
- H3 默认 6 秒 3.0 MP 约 110–130 币/条；10 秒 2.07 MP 约 130–165 币；15 秒默认机器会爆显存。
- 全片 20 条左右约 3000 币，再加三成重抽。余额不够时给两个方案：充值，或精简（爆炸图改 8 秒、合并镜头）。
- 新的一幕先单跑一条测试。
