## 四、画面规则（这部片子里被用户定下来的）

- **以最新定稿为准**：家具对照作者最新的设计报告 PPT 渲染图；连坐材质只认作者提供的三视图（蜂蜜棕细藤、横竖透空）。早期白底图有废弃方案。
- **逐件对照**：每张关键帧和渲染图并排检查：嵌入茶盘三格（水槽 / 沥水格 / 炉位加电水壶）、连坐中间小几和下层木条、展示架四层层板和两侧纸围面、主位椅有 V 撑而客位椅没有。换背景、加人这类局部编辑也会把小部件改坏，本片关键帧共退回重画 20 次。
- **摆位**：按作者平面布置图，主位椅在茶台远侧长边正对茶盘、客位在两端、连坐在近侧，椅子拉进桌沿，不贴板脚。
- **白棚背景对题**：丝带被否，改竹影、细竹、飘落竹叶。
- **线描人 + 真人**：白棚里用白色细线、透明身体的线描人演示用法（学参考片），实景里用固定卡司的真人（米白麻衫主人、灰绿麻裙女客、炭灰麻衫年轻男客）。
- **器物**：只用白瓷、青瓷和本系列的电水壶，不出现紫砂、铁壶。

## 五、声音

- 视频模型自带的声音全部不用（实测是低频轰鸣加嘶声）。
- 配乐给用户 5 首可商用曲试听，用户选「箫 + 琴」搭配；章节首镜对齐琴曲乐句起点。
- 环境声按场景铺：竹棚 → 竹林风，临水 → 湖水 + 鸟鸣，雨景 → 雨 + 檐滴，夜 → 虫鸣，注茶镜头加注茶声；画卷段只有音乐。
- 旁白处音乐按平滑包络压低 9 dB；成片两遍法线性调到约 -18 LUFS。

## 六、交片前自检（实测数据）

| 检查 | v15（被退回） | v16 |
|---|---|---|
| 响度 | -15.9 LUFS | -19.2 LUFS |
| 安静段电平 | -16.1 dB（≈噪底） | -20.1 dB |
| 5 kHz 以上嘶声 | -42.9 dB | -44.4 dB |
| 抖动最严重的镜头（帧差变异系数） | 1.30 / 1.08 | 重抽后 0.24 / 0.31 |
| 0.15 秒硬切 | 47 处 | 0 |
| 加速镜头 | 大部分 1.3–2 倍 | 0 |

命令：`qc.py jitter`（无字幕片段）、`qc.py audio 成片 --compare 上一版`、`compare.py` 逐件对照、整片抽帧。声音最终由作者试听验收。

## 七、用到的脚本

`gpt_web.py`（ChatGPT 网页出关键帧）→ `compare.py`（逐件对照）→ `rh_run.py --secs 6 --mp 3.0 --mp-fallback 2.5,2.07 --key-env …`（两账号并行）→ `qc.py jitter` → `stable_window.py`（挑最稳 3–5 秒）→ `still_push.py`（静图慢推）→ `music_phrases.py`（乐句）→ `cut.py`（画面 + 旁白 + 字幕）→ `mix.py`（配乐 + 环境声 + 让位 + 响度）→ `qc.py audio`。

只当参考，不要把这些画面、旁白直接套到别的产品上。
