# 示例：节序 Nodes in Order · 茶家具系列（画卷结构）

七件茶家具：茶台、主位椅、客位椅、并坐连坐、展示架、吊灯、屏风。视频采用画卷结构：以仇英《竹院品古》为底，延伸成一幅长卷；家具用界画画进画里；片尾出画入真。

## 文件
- `script_v5_scroll.md`：用户确认过的画卷方案，包括第一幕的细分镜和后续几幕的框架。
- `act1_shots.json`：第一幕 6 条视频的 H3 提示词和首尾帧，可以直接给 `rh_run.py --batch` 用（把 `ASSETS/` 换成项目路径）。
- `act1_cut.json`：第一幕粗剪的剪辑配置，给 `cut.py` 用。

## 第一幕的做法和数据
- 长卷 A–E，拼成 9600×1350：右端是引首；中段是原画，左右补宽；左右两侧各外扩两段。Codex 一共画了 5 次。
- 镜头路线（长卷上的 x 坐标）：7200 → 6600 → 5200 → 4000 → 3000 → 1500 → 0，一路向左。
- 6 条视频，每条 8 秒，2.07 MP，共 624 RH 币，每条用时 8–10 分钟。
- 每条的剪辑速度：1.8 / 1.3 / 1.2 / 1.2 / 1.2 / 1.1。成片 39.8 秒。
- 旁白（Uncle_Fu，0.92 倍）：「节序。」「竹有节，茶有序。」「千年来，人们围坐一席。」「器物在变，围坐的方式，没有变。」

## 用户在这个项目里确认过的偏好
- 字幕用白色宋体，不加描边。
- 旁白用 Uncle_Fu，语速稍慢。
- 一步一景、景景相接；结尾出画入真。
- 爆炸图先完整展示，再组装、推近细节。
- 一幕一审。

只当参考，不要把这些画面、旁白套到别的产品上。
